# CKA Scenarios

Complete CKA syllabus practice, organized like the CKS repository. Every topic has four independent KillerCoda stages: learn, required, inferno, and production.

## Cluster Architecture, Installation & Configuration (25%)

1. Manage Role-Based Access Control (RBAC)
2. Use kubeadm to install a basic cluster
3. Manage a highly available Kubernetes cluster
4. Provision underlying infrastructure for Kubernetes
5. Perform a Kubernetes version upgrade with kubeadm
6. Implement etcd backup and restore

## Workloads & Scheduling (15%)

1. Deployments, rolling updates, and rollbacks
2. Configure applications with ConfigMaps and Secrets
3. Use private container registries
4. Understand Pod design
5. Schedule workloads with resource requirements
6. Use DaemonSets
7. Use static Pods
8. Configure and use multiple schedulers
9. Configure container runtime sandboxes
10. Use labels and selectors
11. Use taints and tolerations

## Services & Networking (20%)

1. Understand host networking configuration
2. Understand connectivity between Pods
3. Configure Kubernetes Services
4. Use Ingress controllers and Ingress resources
5. Configure NetworkPolicies

## Storage (10%)

1. Use StorageClasses and PersistentVolumes
2. Understand volume modes, access modes, and reclaim policies
3. Use PersistentVolumeClaims
4. Configure applications with persistent storage

## Troubleshooting (30%)

1. Troubleshoot clusters and nodes
2. Monitor cluster and application resource usage
3. Manage and evaluate container output
4. Troubleshoot Services and networking

Each stage has its own index.json, lesson pages, setup script, and verification script.
